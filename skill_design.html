协作流程
1. 页面数据来自仓库 designs.json（在线加载，加载失败或超时用内置数据）。
2. 编辑某行（费用/类型/稀有度/效果）→ 点行内「提交此版」 → 会打开 GitHub Issue 预填页，点提交即可。维护者合并后，其他人的页面自动出现该版本。
3. 想看某技能别人设计过什么版本：点行内「版本 N」，可逐版查看并「采用此版本」。
4. 离线协作：导出 JSON 发给别人 → 对方改完 导入 JSON（会作为新版本记录）→ 再导出发回或直接提交。
5. 仓库：ranbow400/mewgenics-skill-design
